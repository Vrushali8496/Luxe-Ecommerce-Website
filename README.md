# Fashion Shopping Website

A responsive fashion shopping website built using HTML, CSS, JavaScript, and Bootstrap.  
This project showcases modern UI design for an online clothing and accessories store.

---

## 🚀 Features

- Responsive Navbar
- Hero Banner Section
- Product Categories
- Featured Products
- Fashion Accessories Section
- Modern UI Design
- Mobile Responsive Layout
- Smooth Hover Effects
- Clean and User-Friendly Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
